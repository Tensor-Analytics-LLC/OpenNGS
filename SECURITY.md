# Security

Keep passwords, tokens, clinical files, private database dumps and identifiable genomic data out of public issues. Report vulnerabilities privately through the repository owner's GitHub contact route, using a minimal synthetic reproducer.

Keep the research desktop edition bound to localhost. Administrators can register filesystem roots and approve native runtimes; this edition does not sandbox a hostile workstation administrator. Do not mount the Docker socket into a public API container.

The hosted sample contract disables personal uploads, external imports and arbitrary execution. Authentication, tenant authorization, encrypted secrets and resource reservations are not HIPAA/GDPR/SOC2/ISO certification. Clinical deployment needs independent review, operational controls and assay validation.

Never publish `.state`, local Vault masters, runtime environments, account exports, presigned URLs or private `evidence`. CI uses synthetic inputs without AWS credentials.
